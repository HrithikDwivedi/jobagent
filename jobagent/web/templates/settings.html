Auto-apply

Status: {% if aa.enabled %}enabled since {{ aa.acknowledged_at[:16] if aa.acknowledged_at else '—' }} {% else %}off{% endif %}

How it works. After each agent run, jobs that pass every rule below are approved by this policy (instead of your click) and an auto-apply worker opens the employer's own application form in a real browser, fills it only with facts you confirmed, uploads the job-tailored one-page resume and cover letter, submits, and records "Submitted" only after it sees the employer's confirmation page (screenshot saved as evidence).

It never invents answers: an unknown required question, a CAPTCHA/bot check, or a site it doesn't support sends the job back to you as "Awaiting approval". The worker needs a real browser, so it runs on your PC (python -m jobagent autoapply) or on GitHub Actions — not inside Vercel. Start with python -m jobagent autoapply --dry-run --headed to watch it fill a form without submitting.
